# Features

## Implemented
- Every traffic car gets a traffic radio: vanilla records, records other mods build on them, and other mods' own records.
- Game 2.5 and 2.31: the Mackinaw BMF records on both, the Mizutani Shion (Sport, TDR) records on 2.31 (2.5 fixes those
  itself), all by the script.
